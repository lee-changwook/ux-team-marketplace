# 대조 축과 미결 표시

## 대조 축

글 항목 하나를 아래 6축으로 나눠 봅니다.
축마다 따로 표를 만들지 않습니다. 어긋난 축만 대조표의 "다른 축" 칸과 "차이" 칸에 적습니다.

| 축 | 보는 것 | 글 예 | 정적 파일로 보이는가 |
|---|---|---|---|
| 있음 | 요소가 있는가 | "엑셀 다운로드 버튼을 둔다" | 보입니다 |
| 문구 | 라벨 · 안내 문구 · 빈 상태 문구 | "조회된 내역이 없습니다" | 보입니다 |
| 값 | 기본값 · 정렬 · 상한 · 형식 | "기본 기간은 3개월", "최대 10개" | 소스에 값이 적혀 있으면 보입니다 |
| 조건 | 언제 보이는지 · 켜지는지 | "선택한 행이 있을 때만 활성" | 대개 안 보입니다 |
| 예외 | 오류 · 빈 상태 · 경계 | "0원이면 표시하지 않는다" | 대개 안 보입니다 |
| 흐름 | 화면 이동 · 상태 전이 | "저장하면 목록으로 돌아간다" | 안 보입니다 |

- 항목에 해당하지 않는 축은 보지 않습니다. "기본 기간 3개월"은 값 축만 봅니다.
- 문구는 띄어쓰기 · 문장부호만 다르면 어긋남으로 올리되 "표기만 다름"이라고 적습니다. 맞출지는 기획자가 정합니다.
- 안 보이는 축은 "확인 못 함" 절로 보냅니다. 소스를 읽고 추정한 내용은 "참고"에 "소스로 본 추정"이라고 밝혀 적습니다.

## 매칭이 애매할 때

- 글 항목 하나가 요소 여러 개를 가리키면 요소마다 행을 나눕니다.
- 요소 하나가 글 항목 여러 개에 걸치면 항목마다 행을 나눕니다.
- 같은 요소인지 확신이 없으면 일치로 넣지 않습니다. "어긋남"에 두고 "같은 요소인지 확인 필요"라고 적습니다.

## 미결 표시

### 세는 표시

- `미결`, `미정`, `TBD`
- `QST-NN` 같은 질문 ID
- `확인 필요`, `논의 필요`, `추후`, `나중에`
- 물음표로 끝나는 항목
- 빈 체크박스 `[ ]`

같은 항목에 표시가 여러 개 있으면 1건으로 셉니다.
표시마다 문서 이름, 위치(절 제목 · 몇 번째 줄), 원문을 적습니다.

### 0건일 때 다시 볼 후보

경고 아래에 아래 후보를 줍니다.
후보는 "다시 볼 곳"이지 미결 판정이 아닙니다.

- 아티팩트에만 있는 요소: 글에 적히지 않은 결정입니다.
- 값 축이 비어 있는 항목: 기본값 · 정렬 · 상한이 글에 없는 목록 · 조회 조건
- 예외 축이 비어 있는 항목: 빈 상태 · 오류 · 권한 없음이 글에 없는 화면
- 흐름 축이 비어 있는 버튼: 누른 뒤 어디로 가는지 글에 없는 버튼
