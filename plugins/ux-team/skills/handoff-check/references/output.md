# 출력 양식

대화 본문에 마크다운으로 냅니다.
해당하는 내용이 없는 절은 지우지 말고 "없음"이라고 적습니다. 무엇을 봤는지 남기기 위해서입니다.

## 규칙

- "확정", "통과", "넘겨도 됩니다", "문제없습니다"를 쓰지 않습니다.
- 요약 마지막 줄은 항상 "넘길지는 기획자께서 정하실 일입니다."입니다.
- 글 항목은 원문을 그대로 인용합니다. 줄이거나 고쳐 쓰지 않습니다.
- 높임말로 씁니다.

## 양식

```markdown
## 핸즈오프 점검 결과

> (미결이 0건일 때만) 미결 표시가 0건입니다. 처음 만드는 화면에서 모르는 것이 하나도 없을 수는 없습니다. 다시 봐 주세요.

- 대조 <N>항목: 일치 <a> · 어긋남 <b> · 글에만 <c> · 아티팩트에만 <d>
- 확인 못 함 <e>항목 (그중 일치 (보이는 축만) <f>항목은 위 일치에도 들어 있습니다)
- 미결 표시 <n>건 (<문서별 건수>)
- 직접 확인하실 것 <k>개
- 넘길지는 기획자께서 정하실 일입니다.

### 판단할 것

#### 어긋남
| 글 항목 (원문 · 위치) | 아티팩트 (화면 › 영역 › 요소) | 다른 축 | 차이 |
|---|---|---|---|
| REQ-07 "기본 기간은 3개월" (2절) | 목록 › 조회 조건 › 기간 | 값 | 아티팩트는 1개월로 열립니다 |

#### 글에만 있음
| 글 항목 (원문 · 위치) | 찾아본 곳 |
|---|---|

#### 아티팩트에만 있음 (글에 근거 없음 · 미결 후보)
| 아티팩트 (화면 › 영역 › 요소) | 내용 |
|---|---|

#### 미결 0건일 때 다시 볼 후보
- (axes.md "0건일 때 다시 볼 후보" 기준)

### 확인할 것

#### 확인 못 함
| 글 항목 (원문 · 위치) | 못 본 축 | 이렇게 확인하시면 됩니다 |
|---|---|---|
| REQ-11 "선택한 행이 있을 때만 활성" | 조건 | 행을 하나도 고르지 않은 채로 버튼이 꺼져 있는지 눌러 봐 주세요 |

#### 직접 확인하실 것 (CRS-04)
- [ ] REQ-04 "저장하면 목록 맨 위로": 프로토타입에서 직접 눌러 확인하셨나요?
- [ ] 서브태스크 "개발 전달"을 완료로 바꾸셨나요?
- [ ] 브랜치를 push하셨나요?

### 참고
- 미결 표시: <문서> <위치> "<원문>" …
- 일치 <a>항목: <ID 또는 원문 앞부분> … (못 본 축이 남은 항목은 "보이는 축만"을 붙입니다)
- 소스로 본 추정: <항목> — <추정 내용>
- 읽은 입력: <파일 · 링크> / 못 읽은 입력: <없음 또는 이유>
```
