# Hi-fi 원본 파일 규칙

팀 기획안 Figma 파일(`<기획안 파일>`)을 2026-09-20에 정찰해 실측한 사실들이다. **추측이 아니라 실측이다.** 다른 파일을 다룰 때는 Step 3에서 같은 항목을 다시 확인한다. 본문의 node id는 실측 예일 뿐이니 작업에 쓰지 않는다. fileKey · nodeId는 사용자가 준 URL에서만 뽑는다.

## 1. 원본은 코드가 아니라 화면에서 왔다

base 프레임은 **실행 중인 스테이징 화면의 DOM을 그대로 떠온 것**이다.

| 항목 | 실측값 |
| ---- | ------ |
| 노드 구성 | FRAME 723 · TEXT 220 · VECTOR 95 = 1,038개 |
| INSTANCE · COMPONENT | **0개** — DS 라이브러리를 쓰지 않는다 |
| 레이어 이름 | `Body` · `Navigation` · `Container` · `Link - 고급모드로 이동` · `Image (티키타)` · `Text` — DOM 태그 구조 |
| 내용물 | 실데이터(수업 71개·강사명)와 좌하단 `STAGING` 배지까지 포함 |
| 루트 | `layoutMode: VERTICAL`, 1534×1015 |
| 폰트 | `Pretendard` Regular/Medium/SemiBold/Bold + `42dot Sans` Medium |
| 색 | fill이 **Figma 변수에 바인딩**돼 있다 (`VariableID:4fbf365d…/8345:209`) |

여기서 따라오는 절대 원칙:

> **새로 그리지 말고 복제한다.**
> 색·폰트·라운드·변수 바인딩을 손으로 재현하면 반드시 원본과 어긋난다. 추가할 요소와 **같은 역할의 기존 요소를 `clone()`** 해서 내용만 바꾼다.

원본 작성자가 실제로 그렇게 했다. `[등록 생성]` 버튼은 `[수업 추가]` 버튼의 복제본이고 w·h·radius·fills·strokes·폰트·**변수 바인딩까지 완전히 동일**하며 텍스트만 다르다.

## 2. 이름으로는 못 찾는다 — 텍스트가 앵커다

레이어 이름이 전부 `Container`라 `findAll(n => n.name === '수업들 패널')` 같은 검색은 0건이다. 반드시:

1. 화면에 보이는 **텍스트**로 TEXT 노드를 찾고
2. 거기서 **조상으로 올라가며** 원하는 크기·역할의 프레임을 잡는다

레시피는 [FIGMA_RECIPE.md](FIGMA_RECIPE.md) 2절.

## 3. 네이밍 컨벤션 (팀 기획안 파일)

| 대상 | 형식 | 예 |
| ---- | ---- | -- |
| 화면 프레임 | `<화면명> \| 티키타` | `수업 관리 - 기존 수업 \| 티키타` |
| 모달 | `[Modal] <이름>` | `[Modal] 등록 생성하기` |
| 논의 섹션 | `안건N. <결론까지 담은 한 문장>` | `안건2. [등록 생성] 클릭 시, [Modal] 등록 생성 나타남` |
| 시안 | `시안 N. <구분 기준>` | `시안 1. 등록 유무에 상관 없이 수업들 리스트업` |
| 주제 섹션 | `<상위> > <하위>` | `수업 관리 > 회차/분반 설정` |
| 화살표 | `<출발 요소> --> <도착 프레임명>` | `Button 등록 3개 생성 --> [Modal] 등록 생성하기` |

제안 섹션을 새로 만들 때는 `[<이름>] <날짜> <주제>` 형태를 쓴다 (예: `[<작성자> 제안] 0918 수업 생성 → 등록 자동 생성`). 작성자 이름은 사용자에게 한 번 묻고 승인 게이트의 "신규" 줄에 보여 준다.

## 4. 화살표는 CONNECTOR가 아니라 VECTOR다

**Plugin API는 design mode에서 `CONNECTOR` 노드 생성이 차단돼 있다.** 원본 작성자도 쓰지 않았다 — 페이지 전체 227개 최상위 노드 중 진짜 CONNECTOR는 2개뿐이고 무관한 프레임 소속이다.

실측한 화살표 스펙:

- `VECTOR`, stroke `{r:1, g:0, b:0}` (빨강), `strokeWeight: 2`, `dashPattern: []`
- 꺾임 경로를 정점으로 표현 (예: 4정점 = ㄱ자 2번)
- **마지막 정점만 `strokeCap: 'ARROW_LINES'`**, 나머지는 `ROUND`
- 페이지/섹션 최상위에 둔다 (프레임 자식이 아니다)

## 5. 섹션 관용구

- `SECTION`은 이름이 캔버스에 라벨로 표시된다 → **h=9짜리 얇은 SECTION을 라벨 스트립으로** 쓴다
- 시안 묶음은 `SECTION` 안에 `시안 1` / `시안 2` FRAME을 세로로 쌓는다 (실측 521×1280 안에 443×515 두 개)
- 섹션 자식의 x·y는 **섹션 로컬 좌표**다 (base는 section 로컬 6480,6161 / section 절대 44540,18812)

## 6. 검증된 함정 (전부 실측으로 밟았다)

### 6-1. Pretendard가 로드 안 될 수 있다

내 컴퓨터에 설치돼 있어도 Figma가 인식하지 못하는 경우가 있다. 그러면:

- `figma.loadFontAsync({family:'Pretendard', …})` → `The font family "Pretendard" does not exist`
- **기존 텍스트의 `characters` 교체가 통째로 실패한다** (canonical recipe인 `getStyledTextSegments` 경로도 똑같이 실패)
- 그러나 `clone()`과 `appendChild()`는 **폰트 로드 없이도 정상 동작한다** — 복제 자체는 막히지 않는다

대체 폰트는 `42dot Sans`(Bold/ExtraBold/Light/Medium/Regular/SemiBold). 이 파일이 이미 쓰는 폰트라 이질감이 가장 적다. `Noto Sans KR` · `Gothic A1` · `IBM Plex Sans KR`도 사용 가능하다.

### 6-2. 텍스트를 바꾸면 고정폭에 잘린다

버튼 프레임은 `layoutSizingHorizontal: 'FIXED'`(54px)다. 라벨을 `등록 일괄 생성 (3)`으로 바꾸면 텍스트 88px이 54px 안에서 잘린다.

**교체 직후 `layoutSizingHorizontal = 'HUG'`** — 실측 54 → 97px로 늘어나며 정상 표시된다. 부모가 오토레이아웃이면 형제 배치도 따라 조정된다.

### 6-3. Figma 코드 실행은 에러 시 호출 전체를 롤백한다

세 번 겪었다 — 폰트 에러로 중단됐을 때 그 전에 만든 SECTION·clone이 남지 않았고(페이지 children 227개 유지), 주석 부착 중 노드 하나가 `null`이었을 때 **같은 호출에서 이미 성공한 주석까지** 사라졌다.

그래서 한 호출에 여러 대상을 다룰 때는 **대상마다 가드**를 둔다. 자세한 대처는 6-9절.

### 6-4. 정리 검색은 이름 prefix로

임시 노드는 `[SMOKE TEST]` 같은 고정 prefix를 붙이고, 정리할 때 `page.findAll(n => n.name.indexOf(prefix) >= 0)`으로 훑는다. `page.children`만 보면 섹션 안으로 들어간 노드를 놓친다.

### 6-5. 캡처본은 폰트가 없으면 오토레이아웃이 넘친다

Pretendard가 없는 환경에서 캡처본을 열면 대체 폰트로 렌더돼 **텍스트가 실제보다 넓어진다.** HUG 컨테이너가 그만큼 부풀어 부모의 콘텐츠 영역을 넘고, 그러면 **padding이 안 먹힌 것처럼 보인다.** padding 값 자체는 멀쩡하다 — 범인은 자식 폭이다.

실측 (등·하원 내역, 2026-09-20):

| 대상 | 실제 DOM | 캡처본 |
| ---- | -------- | ------ |
| Navigation | 1800, `padding 8px 24px` | **동일** (padding 정상) |
| 좌측 메뉴 Container | 1479 | 1557 (+78) |
| 우측 버튼 Container | 214, right **1776** | 224, right **1805** |
| 자식 합 vs 콘텐츠 1752 | 1693 (여유 59) | 1781 (**29 초과**) |

고치는 순서 (실측으로 두 번 다듬은 순서다):

1. **부푼 쪽을 줄이지 말고, 반대쪽을 줄인다.** 우측 버튼 그룹 같은 고정 성격 자식은 `layoutSizingHorizontal = 'HUG'`로 두어 **자기 자식에 맞는 자연 폭**을 유지한다. 실제 DOM 폭(214)으로 줄였더니 그 안의 버튼이 대신 10px 탈출했다 — 캡처본의 HUG 폭은 이미 부푼 텍스트에 맞춰진 값이라 줄이면 내부가 깨진다
2. **반대쪽 그룹**을 `콘텐츠폭 − 자연폭`으로 `resize()`한다. SPACE_BETWEEN이면 이 한 번으로 우측 끝이 padding 경계에 정확히 붙는다 (1752 − 224 = 1528 → 우측 끝 1776)
3. 남은 내부 초과분은 **반복 요소의 `itemSpacing`을 1씩 줄여 흡수**한다. 링크 24개면 8px → 6px로 46px이 흡수된다
4. 검증 기준은 **"자식이 부모 박스를 벗어나는가"**(`maxRight > frame.width`)다. padding을 조금 침범하는 정도(버튼 안 텍스트 2~4px)는 화면에 드러나지 않으므로 손대지 않는다 — 실측에서 오버플로우 28건 중 진짜 문제는 1건뿐이었다

브라우저 실측은 여전히 한다. 다만 **목표값 확인용**이지 그 값을 그대로 박는 용도가 아니다.

`itemSpacing`을 건드리면 실제와 1~2px 달라진다. Pretendard가 설치된 환경에서는 그만큼 좁아 보이므로 **조정값을 보고에 남긴다.**

### 6-6. 캡처는 화면 상태를 그대로 찍는다

빈 목록을 캡처하면 빈 목록이 그대로 문서가 된다. 실제로 등·하원 내역을 기간 기본값(오늘 하루)으로 캡처했더니 `0건 · 등·하원 기록이 없습니다`가 그대로 들어갔다. 캡처 전에 **조회를 실행해 데이터를 띄우고**, 보여주려는 탭·필터·선택 상태를 맞춘다.

### 6-7. 캡처는 `nodeId`가 없으면 첫 페이지 저 멀리에 떨어진다

도구 설명은 "새 페이지가 생성된다"고 하지만, 실측에서는 **파일의 첫 페이지**(`0:1`)의 `x=28937, y=0`에 생겼다. 사용자가 보던 페이지가 아니면 그냥 안 보인다.

- `nodeId`에 **그 페이지에 있는 아무 노드**를 주면 그 페이지로 들어간다. 다만 그 노드의 자식이 되지는 않는다 (빈 프레임을 지정했으나 페이지 최상위에 생성됐다)
- 그러므로 `nodeId`는 "부모 지정"이 아니라 **"페이지 지정"**으로 이해한다
- 캡처 직후 Figma 코드 실행으로 의도한 섹션·좌표로 옮기고, **결과 URL을 반드시 사용자에게 준다** (`…/design/<fileKey>?node-id=<id>`)

### 6-8. 주석은 Dev Mode 전용이고, 카테고리가 중복될 수 있다

- **Annotation은 Dev Mode(`Shift+D`)에서만 보인다.** Design 모드 우클릭 메뉴에는 주석 항목이 아예 없고 우측 패널에도 섹션이 없다. 편집 메뉴(`컴포넌트 만들기`·`오토레이아웃 제거`)가 보이면 아직 Design 모드다
- 그래서 **주석만으로 전달이 끝나지 않는다.** 개발자가 아닌 사람은 대개 Design 모드로 열기 때문에 Design 모드에서도 읽히는 Description 카드가 따로 필요하다
- 카테고리는 파일마다 다르고 **같은 이름이 둘 이상일 수 있다** (실측: `API`가 노랑 `6:4`·파랑 `1:10` 두 개). 지어내지 말고 `getAnnotationCategoriesAsync()`로 읽은 뒤, 기존 주석이 실제로 쓴 쪽을 따른다
- 주석은 TEXT·FRAME·VECTOR 어디에든 붙는다. 시트는 Dev 또는 Full이 필요하다

### 6-9. 노드 id는 사용자 편집으로 바뀐다 — write 직전에 재탐색한다

사용자가 캡처를 다른 섹션으로 옮기거나 이름을 바꾸면 **id가 새로 발급된다** (실측: `6300:2114` → `6305:7990`). 정찰 때 박아둔 id로 바로 쓰면 `cannot set property 'annotations' of null`이 난다.

그리고 6-3절대로 **Figma 코드 실행은 에러가 나면 그 호출 전체를 롤백**하므로, 같은 호출에서 이미 성공한 주석까지 사라진다. 그래서:

- 앵커는 **텍스트 내용으로 다시 찾고** 조상으로 올라간다. id는 캐시가 아니라 힌트다
- 대상마다 `if (!node) { skipped.push(...); continue; }` 가드를 둔다
- 부착 뒤 **별도 호출로 확인한다.** 롤백 여부를 알 수 있는 유일한 방법이다

## 7. 금지

- 색·폰트·간격을 **하드코딩으로 재현**하는 것 (1절)
- 레이어 이름 기반 노드 검색 (2절)
- `CONNECTOR` 생성 시도 (4절)
- 폰트 대체를 사용자에게 알리지 않고 진행 (6-1절)
- 원본 작성자가 만든 **기존 노드를 직접 수정** — 언제나 clone 위에서 작업한다
- 승인 없이 write
- 주석 카테고리를 지어내기 (파일에서 읽는다)
- Description 카드 스타일을 추측으로 만들기 (관행 프레임에서 실측해 복제한다)
- 기획 원문과 코드가 어긋날 때 **원문을 고치기** — verbatim으로 옮기고 충돌을 보고한다
