# tikita-policy

티키타 정책 위키를 찾아 읽고 근거를 밝혀 답하는 스킬이다.
지금은 준비 중이다. 이 플러그인은 공개 저장소에 있어서 위키 사본을 담지 않는다.
위키는 회사 GitHub 조직의 저장소로 옮겨 협력자만 읽게 할 예정이다. 그 저장소가 생기면 이 스킬이 거기서 읽도록 바뀐다.

## 어디서 되는가

| 화면 | 되는 것 | 안 되는 것 |
|---|---|---|
| Chat · Cowork · Code 탭 | 준비 중 안내, 붙여 넣은 자료 안에서 답하기, 미결 정리 | 위키 읽기 (아직 연결 전) |

## 지금 하는 일

1. 정책 위키가 아직 연결되지 않았다고 한 줄로 알린다.
2. 정책 내용을 지어내지 않는다. 비슷한 정책이나 일반적인 학원 관행으로 채우지 않는다.
3. 사용자가 대화에 붙여 넣은 위키 글이나 자료가 있으면 그 안에서만 답하고, 어느 부분을 근거로 했는지 밝힌다.
4. 근거로 삼을 자료가 없으면 `미결`로 답하고 세 가지를 적는다.
   - 무엇이 없는지
   - 무엇이 필요한지: 어떤 정책 · 정의인지
   - 누구에게 물을지: 리드. `call-lead`로 부를 수 있다고 알린다.
5. 기획자가 정해야 할 일이면 `decision-log`로 결정을 남길 수 있다고 알린다. 직접 남기지는 않는다.

## 코드 · 주소에서 만나는 로마자 표기

화면 주소, API 경로, 코드 이름에서 도메인 용어는 로마자로 적힌다.
헷갈리기 쉬운 것부터 적는다.

| 용어 | 표기 |
|---|---|
| 청구 | `Cheonggu` (`Chungu` 아님) |
| 수납 · 결제 · 미납 | `Sunap` · `Gyeolje` · `Minap` |
| 수업 · 콘 · 분 · 워크 | `Sueop` · `Kon` · `Boon` · `Work` |
| 재원생 · 수강생 | `Jaewonsaeng` · `Sugangsaeng` |
| 출결 · 학원 알림 · 수업 검증 | `Chulgyeol` · `Hagwon-allim` · `Sueop-geomjeung` |

## 하지 않는 것

- 정책을 추측으로 채우지 않는다.
- 위키도, 코드도, 화면도 고치지 않는다.
- 티링(학생 · 보호자 앱) 정책은 아직 이 스킬에 없다.
