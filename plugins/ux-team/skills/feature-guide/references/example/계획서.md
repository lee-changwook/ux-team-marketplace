# 보강 신청 화면 계획서 (가상 예시)

> feature-guide 스킬의 예시 입력이다. 기능 · 학원 · 사람 · 연락처는 모두 가상이다.

## 범위
행정 모드에 `보강 신청` 화면을 더한다. 보호자가 앱에서 보낸 보강 신청을 행정팀이 모아 보고 일정을 정한다.

## 요구사항
1. 메뉴 `보강 신청`에서 신청 목록을 본다. 열: 재원생 · 보호자 연락처 · 수업 · 결석일 · 희망 보강일 · 상태
2. 위쪽 칩(`대기` · `승인` · `반려`)으로 상태별로 거른다. 칩에는 건수가 붙는다.
3. `대기` 신청에는 `일정 정하기` · `반려` 버튼이 있다.
4. `일정 정하기`를 누르면 `보강 일정 정하기` 창이 뜬다. 보강 날짜 · 시간 · 담당 강사를 고르고 `일정 저장`을 누르면 상태가 `승인`으로 바뀐다.
   - 창의 날짜는 처음에 희망 보강일로 채워진다.
   - `저장하면 보호자에게 보강 일정 알림을 보냅니다`가 켜져 있으면 저장할 때 보호자에게 학원 알림이 간다. 끄면 보내지 않는다.
5. `반려`를 누르면 확인 창(`이 보강 신청을 반려할까요?`)이 뜨고, `반려하기`를 누르면 상태가 `반려`로 바뀐다. 반려 사유 입력은 이번 범위에 없다.

## 화면 문구 (코드 기준이라고 가정)
- 확인 창: `이 보강 신청을 반려할까요?` / 버튼 `취소` · `반려하기`
- 저장 토스트: `보강 일정을 저장했습니다.`
