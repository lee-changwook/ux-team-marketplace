# 보강 신청 매뉴얼 캡처 목록 (가상 예시)

- 캡처는 **테스트 조직 · 가명 재원생**으로 찍는다 (실명 · 실제 전화번호 금지)
- 파일 이름은 아래 그대로, 원고와 같은 폴더에 넣는다. 없는 파일은 PDF에 `캡처 없음` 자리만 남는다
- 번호 배지(빨간 원)는 원고의 번호 설명과 같은 번호를 가리키는 요소 바로 옆 빈자리에 얹는다
- 뷰포트 넓게(1100 이상) · 배율 2 권장

| 파일 | 화면 | 배지 |
|---|---|---|
| `00_보강신청목록.png` | `보강 신청` 화면 전체, `대기` 칩을 고른 상태 | ① 상태 칩 ② `일정 정하기` ③ `반려` |
| `01_일정정하기.png` | `일정 정하기`를 눌러 뜬 `보강 일정 정하기` 창 | ① 보강 날짜 · 시간 ② 담당 강사 ③ 알림 체크 ④ `일정 저장` |

## 현황 (2026-10-15)

- `원본/`의 캡처는 가공 전 원본이다. 가공 spec(`원본/*.json`)으로 이 폴더의 가공본을 다시 만들 수 있다
- `00_보강신청목록.png` — 첫 줄 재원생 이름 `홍길동` → `정예린`, 보호자 연락처 4개를 `010-9***-5***` 꼴로 일부 가림
- `01_일정정하기.png` — 창 윗줄 재원생 이름 `홍길동` → `정예린` (목록과 같은 가명)
- 미결: 반려 확인 창 캡처는 없다. 원고에는 글로만 둔다
- 미결: 알림을 끄고 저장했을 때 화면에 따로 안내가 뜨는지는 계획서에 없어 원고에 쓰지 않았다
