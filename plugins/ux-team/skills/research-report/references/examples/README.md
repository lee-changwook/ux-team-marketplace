# 가상 예시

판본마다 하나씩, 입력 자료와 완성 리포트를 함께 담았다.
학원 · 응답자 · 답 · 날짜는 모두 지어낸 것이다. 실존 학원 · 사람 · 실제 응답과 관계없다.
처음 쓰거나 판단이 애매하면 이 리포트의 구조와 문장 톤을 따라 한다.

## 비교형 (`비교형/`)

- 자료: 같은 질문 리스트로 A학원 · B학원 원장님을 인터뷰한 메모 2개 (`질문 리스트_A학원.md`, `질문 리스트_B학원.md`)
- 리포트: `미납 안내 인터뷰 정리.html`
- 만든 명령: `md_to_qs.py <A학원.md> <B학원.md> --keys a,b` → 문항 12개 중 양쪽 모두 답함 11개 (92%), 판정 비교형
- 동의 확인: 두 원장님이 서로의 답을 봐도 된다고 동의했다는 전제로 만들었다 (SKILL.md 0절)
- 보여 주는 것
  - B학원의 `(제안)` 줄은 응답에서 빠져 12번이 "답하지 않음"으로 나오고, 함께 이야기할 것에서 "여쭤보지 못했습니다"로 다시 묻는다
  - `(녹음)` 표시는 떼고 옮겼다 (7번)
  - 대결 카드 6장 중 함께 정할 것 3장. 공통점은 같은 질문에 같은 방향으로 답한 3개
  - 3열 블록(`.roles`)을 지우고 흐름부터 썼다. 준비 섹션은 "먼저 살펴볼 것", 제안 섹션은 "개선 방향 제안"
  - 응답자가 사람이라 "두 분" 고정 문구를 그대로 두었다

## 단일형 (`단일형/`)

- 자료: C학원 현장 테스트 질문 리스트 1개 (`질문 리스트_C학원.md`). 지금 쓰는 종이 출석부 관찰과 새 출결 화면 테스트 반응이 섹션마다 다른 질문으로 들어 있다
- 리포트: `출결 화면 현장 테스트 정리.html`
- 만든 명령: `md_to_qs.py <C학원.md>` → 문항 15개 중 답 있음 14개, 판정 단일형
- 보여 주는 것
  - 답이 없는 문항(원장님이 보고 싶은 것)은 문항 목록에서 빠지고, 먼저 살펴볼 것에 "여쭤보지 못했습니다"로 남긴다
  - 관찰 대상이 둘이어도 같은 질문을 두고 답이 갈린 2곳만 대결 카드로 만들었다. 같은 방향인 것이 없어 공통점 블록은 지웠다
  - 현장 환경 문항(1~3)은 표지 `현장 환경` 칸에 옮기고 비교에 넣지 않았다
  - 작성자의 아이디어(`(제안)` 줄, 결석 문자 버튼)는 응답에서 빼고, 제안 섹션 레일에 흐름에 넣지 않은 이유를 밝혔다
