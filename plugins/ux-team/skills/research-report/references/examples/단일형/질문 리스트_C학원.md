# 출결 화면 현장 테스트 (가상 예시) · C학원

## 구성
- **PRE. 현장 환경**
- **A. 지금 쓰는 방식 관찰**
- **B. 새 출결 화면 테스트**

## PRE. 현장 환경
- 데스크에 있는 사람
	- 실장님 한 분, 오후 2시부터 9시까지
- 데스크 기기
	- 데스크톱 PC 1대, 태블릿은 없음
- 학생 수와 몰리는 시간
	- 초등 60명, 3시~6시에 몰림 (녹음)

## A. 지금 쓰는 방식 관찰
### 출석 확인
- 학생이 들어오면 출석을 어디에 적나요? [사진 촬영]
	- 데스크 종이 출석부에 체크
	- 반별로 한 장씩, 클립보드에 꽂아 둠
- 출석 체크에 걸리는 시간
	- 한 명에 2~3초. 몰릴 때는 데스크 앞에 줄이 생김 (녹음)
- 늦은 학생 표시
	- 이름 옆에 도착 시간을 손으로 적음
### 결석 연락
- 수업 시작 후 안 온 학생은 언제 확인하나요?
	- 수업 시작 10분 뒤에 실장님이 출석부를 훑어봄
- 학부모 연락은 어떻게 하나요?
	- 전화. 안 받으면 문자
- 결석 연락 기록은 어디에 남기나요?
	- 출석부 여백에 "母 통화" 식으로 적음

## B. 새 출결 화면 테스트
### 첫 사용
- 화면을 처음 보고 무엇부터 눌렀나요?
	- 반 목록에서 오늘 반을 먼저 찾음
	- 오늘 수업 있는 반만 보이면 좋겠다고 함
- 출석 체크에 걸리는 시간
	- 이름 검색까지 하면 한 명에 10초 정도
- 늦은 학생 표시
	- 지각 버튼을 바로 찾음. 도착 시간이 자동으로 찍히는 걸 좋아함
### 반응
- 종이 출석부와 비교하면 어떤가요?
	- 몰리는 시간에는 종이가 더 빠를 것 같다
	- 대신 안 온 학생이 바로 보이는 건 좋다
- 결석 학생 학부모에게 화면에서 바로 연락할 수 있다면 쓰겠나요?
	- 전화번호가 같이 보이면 쓰겠다
	- 결석 문자 자동 발송 버튼 (제안)
- 원장님이 이 화면에서 보고 싶은 것
