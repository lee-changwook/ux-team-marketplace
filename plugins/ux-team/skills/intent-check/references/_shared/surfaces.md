# 화면 판별과 분기

## 판별
1. 로컬 셸이 macOS이고 `~/.claude` 폴더를 읽을 수 있으면 Code 탭이다. Cowork의 격리 환경에도 `~/.claude`가 있을 수 있어 macOS인지 함께 본다.
2. 그렇지 않으면서 사용자가 연결한 로컬 폴더가 있으면 Cowork다.
3. 둘 다 아니면 Chat이다.
4. 판별이 애매하면 지금 쓰는 화면이 Chat · Cowork · Code 탭 중 무엇인지 사용자에게 묻는다.

## 화면별로 되는 것
아래는 기본 가정이다. 통합 단계에서 실제로 확인하고 고친다.

| 기능 | Chat | Cowork | Code 탭 |
|---|---|---|---|
| 내 컴퓨터 파일 읽기 · 쓰기 | 안 됨 (올린 파일만) | 연결한 폴더만 | 됨 |
| 명령 실행 | 격리된 실행 환경 | Anthropic 서버의 격리 환경 | 내 Mac |
| macOS 전용 도구 (Swift, Chrome 앱) | 안 됨 | 안 됨 | 됨 |
| 브라우저 조작 | 안 됨 | 내장 브라우저 | Claude in Chrome 확장이 있을 때 |
| 커넥터 (ClickUp · Slack · Figma) | 됨 | 됨 | 계정 커넥터가 따라옴 |
| 티키타 레포 코드 | 안 됨 | 레포 폴더를 연결한 경우만 | 레포를 연 경우 |

## 분기 원칙
- 지금 화면에서 안 되는 단계는 조용히 건너뛰지 않는다. 어디서 하면 되는지 알리고 멈춘다.
- 대신할 수 있는 단계가 있으면 사용자에게 고르게 한다. 예: PDF가 안 되면 HTML로 만들지 묻는다.
- 비밀번호 · 토큰 · 로그인은 다루지 않는다. 로그인이 필요하면 사용자가 직접 하도록 안내한다.
