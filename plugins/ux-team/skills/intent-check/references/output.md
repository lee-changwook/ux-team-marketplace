# 출력 양식

대화 본문에 마크다운으로 냅니다.
해당하는 내용이 없는 절은 지우지 말고 "없음"이라고 적습니다.

## 규칙

- "확정", "통과", "문제없습니다"를 쓰지 않습니다.
- 기대는 원문 그대로 인용합니다. 실제는 화면에서 본 것을 적고, 화면 문구는 그대로 인용합니다.
- 차이마다 근거(캡처 번호 · 주소 · 도달 경로)를 붙입니다. 근거가 없으면 "차이"에 넣지 않습니다.
- 높임말로 씁니다.

## 확인 못 함 이유

| 이유 | 뜻 |
|---|---|
| 쓰기 필요 | 확인하려면 저장 · 발송 등 쓰기 동작이 필요합니다 |
| 쓰기 가능성 | 눌렀을 때 무엇이 일어날지 몰라 누르지 않았습니다 |
| 판정 기준 없음 | 기대가 화면으로 판정할 수 있는 말이 아닙니다 |
| 데이터 없음 | 그 상태인 데이터를 조회로 찾지 못했습니다 |
| 도달 못 함 | 화면을 찾지 못했거나 권한 · 오류로 열리지 않았습니다 |
| 감지로 멈춤 | GET이 아닌 요청이 생겨 멈췄습니다 |

## 양식

```markdown
## 의도 확인 결과 (<주소 호스트> · <날짜 시각>)

- 확인 단위 <N>개: 의도와 같음 <a> · 차이 <b> · 확인 못 함 <c>
- 쓰기 동작 0건, 이동한 주소는 모두 허용 목록 안이었습니다.
- (멈춘 적이 있으면) <무엇을 눌렀더니> <어떤 요청>이 생겨 멈췄습니다.
- 차이가 버그인지 의도 변경인지는 기획자께서 판단하실 일입니다.

### 판단할 것: 차이
| 항목 | 기대 (원문) | 실제 (관찰) | 근거 |
|---|---|---|---|
| REQ-07-a | "기본 기간은 3개월" | 기간이 1개월로 열립니다 | 캡처 3 · <주소> · 메뉴 › 납입 분석 |

### 확인할 것: 확인 못 함
| 항목 | 이유 | 이렇게 확인하시면 됩니다 |
|---|---|---|
| REQ-04 | 쓰기 필요 (저장 후 동작) | 시험 데이터로 직접 저장해 보시고 목록 맨 위에 오는지 봐 주세요 |
| REQ-12 | 판정 기준 없음 ("눈에 잘 띄게") | 캡처 9를 보시고 판단해 주세요 |

### 참고: 의도와 같음
| 항목 | 근거 |
|---|---|
| REQ-02-a | 캡처 1 |

### 참고: 확인 경로
- 연 주소: <목록>
- 화면: Cowork 내장 브라우저 / Code 탭 Claude in Chrome
- 네트워크 감시: 했음 / 못 함 (이유)
```
