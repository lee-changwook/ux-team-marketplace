# 가상 예시

모든 기관·인물·상황은 가상입니다. 실제 티켓이나 컬럼 설정을 뜻하지 않습니다.
필요한 사례만 참고합니다.

## 오류: 짧은 메모

입력:

> 오류 티켓 초안만 작성해 주세요. 예시학원 행정팀이 운영 티키타 웹에서 알림 발송 > 미연동 대상을 골라 대체 발송을 체크하고 보냈는데 문자가 오지 않았다고 했습니다. 원하는 건 선택한 미연동 대상에게 대체 문자가 가는 것입니다. 제가 재현해 보지는 않았고 사진은 아직 없습니다.

출력:

```markdown
제목: [알림 발송] 미연동 대상의 대체 문자가 전달되지 않음

**1. 화면 위치·발생 조건**
- 작업 구분: 미확인 (발송 결과 문제라 화면만으로 가를 수 없음)
- 세부 화면 경로: 알림 발송 > 발송 대상 선택
- 대상 및 발생 조건: 미연동 대상 선택, 대체 발송 선택
- 제품·환경·요청 기관: 티키타 웹 / 운영 / 예시학원 (컬럼 적용 여부 미확인)

**2. 현재 현상·불편**
- 현재 현상: 행정팀 보고에 따르면 발송 후 대상에게 문자가 도착하지 않음. 작성자는 재현하지 않음
- 업무상 불편 사항: 해당 대상에게 안내가 전달되지 않음. 전체 실패 범위는 미확인
- 임시 해결 방법: 미확인

**3. 재현·사용 순서**
1. 보고된 순서: 미연동 대상을 선택합니다.
2. 대체 발송을 선택하고 발송합니다.
3. 문자 수신 여부를 확인합니다. 작성자가 이 순서를 직접 재현한 것은 아닙니다.

**4. 기대 결과·완료 조건**
- 기대 결과: 선택한 미연동 대상에게 대체 문자가 전달됨
- 완료 조건:
- [ ] 같은 조건으로 발송한 뒤 대상의 문자 수신을 확인할 수 있음

**5. 관련 자료·결정 필요 사항**
- 사진·영상: 아직 제공되지 않음
- 관련 링크: 없음
- 확인·결정 필요 사항: 재현 여부와 발송 실패 범위 확인 필요
```

컬럼 후보: 제품=티키타 웹(입력), 요청 기관=예시학원(입력), 접수일=오늘(작성일), 접수 담당자=작성자(판단, 선택지에 있을 때).
환경=운영, 업무 영역=알림·문자, 요청자=예시학원 행정팀은 그런 칸이 없으면 본문 1절에 둡니다.
접수 경로·회신 상태는 근거가 없어 비우고, 기본 담당자·우선순위·기한은 지정하지 않습니다.
초안만이므로 실제 칸을 조회하거나 등록하지 않고 적용 여부를 미확인으로 둡니다.

## 개선: 요청과 아이디어 구분

입력:

> 개선사항 초안 만들어 주세요. 미납 관리의 ‘수납 관리’ 버튼이 어떤 일을 하는지 모르겠다는 의견이 있습니다. ‘수납 생성 및 알림 발송’으로 이름을 바꿔 주세요. 아이콘도 바꾸면 좋을 것 같지만 그건 아직 결정 전입니다.

- 제목: `[미납 관리] 수납 관리 버튼명을 수납 생성 및 알림 발송으로 변경`.
- 현재 현상은 전달받은 사용자 의견으로 적고, 조사 인원·불편 빈도는 지어내지 않습니다.
- 완료 조건은 해당 화면의 버튼명 변경만 둡니다. 클릭 후 동작이나 다른 화면까지 변경 범위를 늘리지 않습니다.
- 작업 구분은 `FE (추정: 버튼 문구만 바뀜)`으로 둡니다.
- 아이콘 변경은 본문 5절에 `미결: 아이콘 변경 여부`로 둡니다. 완료 조건에는 넣지 않습니다.
- 제품은 화면 이름과 선택지로 가를 수 있으면 판단해 채우고, 애매하면 비우고 확인 질문에 넣습니다. 기관은 입력에 없으니 필수 칸이면 등록 전에 묻습니다.

## 이미지와 정보 부족

입력:

> 오류 티켓 초안만 만들어 주세요. 이 팝업에 400이 떠요. (오류 메시지만 보이는 이미지 첨부)

- 확인 가능한 오류 문구만 관찰 사실로 옮깁니다. 이미지의 파일명이 오류 위치·기관·버전의 근거가 되지는 않습니다.
- 경로·조작 순서·기대 결과는 미확인으로 둡니다. 위치와 직전에 한 동작을 묶어 확인합니다.
- BE 원인, 전체 사용자 영향, 서버 복구 필요를 추정하지 않습니다. 작업 구분은 `미확인`입니다.
- 이미지 첨부는 초안의 예정 자료이며, 티켓에 저장했다고 보고하지 않습니다.

## 일부 실패와 재시도

가상 결과: 티켓 생성은 성공해 ID와 링크를 받았지만 환경 컬럼 설정에 실패했습니다. 첨부는 성공했습니다.

- 결과는 `일부 적용`입니다. 생성된 티켓 링크, 저장된 첨부, 환경 컬럼 실패 원인을 알려 줍니다.
- 다시 시도하라는 요청은 그 티켓의 실패한 컬럼 설정만 대상으로 합니다. 티켓 생성이나 성공한 첨부를 반복하지 않습니다.
- 생성 자체가 시간 초과로 끝나 ID가 없다면 같은 목록·제목·시점으로 제한 조회합니다. 성공 여부를 판단할 수 없으면 새 생성은 멈춥니다.
