# decision-log eval

ACC · DEC · QST 번호는 `docs/00-명세.md`, CRS 번호는 `shared/crossings.md`의 것이다.
결정 기록을 남길 곳(QST-05)이 정해지지 않아 `team-places.md`의 결정 기록 행이 `<미정>`이다. 기능 확인은 초안 출력까지만 한다. 댓글을 읽어 번호를 세거나 남기는 확인은 리드가 시험용 태스크를 정해 준 뒤에 한다.

## 켜져야 할 요청
1. 이거 결정됐어. 결제 내역 기본 기간은 3개월로 하기로 했어
2. 결정 기록 남겨 줘. 오늘 회의에서 열람 상태는 안 보여 주기로 정했어
3. 정한 내용 정리해 둬, 채널은 티링만 쓰기로 했어
4. 어제 리드랑 수업 그룹 최대 10개로 정했는데 중앙 컨텍스트에 남겨 줘
5. 지난번 DEC-03 바뀌었어, 이제 6개월로 하기로 했어

## 켜지면 안 될 요청
다른 스킬이 맡는 말을 넣는다 (`docs/01-트리거 지도.md`의 "겹치는 말 정리").

| 요청 | 대신 맡는 스킬 |
|---|---|
| 오늘 회의 내용 전부 요약해 줘 | 없음. 회의 전체 요약은 맡지 않는다 |
| 인터뷰 정리해 줘 | `research-report` |
| 막혔어, 리드한테 물어봐 | `call-lead` |
| 프로젝트 배정됐어 | `kickoff` |
| 청구와 수납 용어 차이 알려 줘 | `tikita-policy` |

## 기능 확인
| 확인 | 화면 | 기대 결과 | 관련 ACC |
|---|---|---|---|
| 결정 · 누가 · 언제 · 근거를 주고 실행 (남길 곳 `<미정>`) | 모두 | 태스크 링크를 줄지, 복사할 글만 받을지 묻는다 | ACC-37 |
| 복사할 글만 받기 | 모두 | `DEC-??`로 시작하는 결정 기록과 "마지막 번호 다음으로 바꿔 주세요" 안내가 나온다. 쓰기 호출이 0건이다 | ACC-37 · ACC-39 |
| 근거를 주지 않음 | 모두 | 근거를 한 번 묻는다. 그래도 없으면 근거 줄이 "근거 미기재"이고 초안 위에 "근거 없이 남깁니다." 줄이 있다. 근거를 지어내지 않는다 | ACC-38 |
| "10/13 회의에서 정했어"만 말함 | 모두 | 그 말이 "누가" · "언제" 칸에 들어가고 근거 칸에 들어가지 않는다. 근거를 한 번 묻는다 | ACC-38 |
| 이유가 앞선 대화에서만 나옴 | 모두 | 그 말을 인용해 "이것을 근거로 적을까요?"라고 묻는다. 묻기 전에 근거 칸을 채우지 않는다 | ACC-38 |
| "~로 하면 좋겠다"처럼 말함 | 모두 | 정해진 것인지 묻고, 아직이면 남기지 않는다 | ACC-37 |
| "DEC-03 바뀌었어" | 모두 | 초안에 `대체: DEC-03` 줄과 옛 기록에 달 대체 답글이 함께 있고, 한 번에 확인을 묻는다 | ACC-39 |
| 시험 태스크에 DEC-01 · DEC-02 · DEC-05가 있음 (시험 태스크 필요) | 모두 | 새 번호가 `DEC-06`이다. 빈 번호 03 · 04를 다시 쓰지 않는다 | ACC-39 |
| 승인 전에 다른 사람이 DEC-06을 남김 (시험 태스크 필요) | 모두 | 남기기 직전에 다시 세어 `DEC-07`로 고친 초안을 보여 주고 다시 확인받는다 | ACC-39 |
| 승인 후 남기기 (시험 태스크 필요) | 모두 | 결정 한 건이 댓글 한 개로 남고 링크를 준다 | ACC-37 |
