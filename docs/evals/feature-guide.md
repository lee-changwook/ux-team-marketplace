# feature-guide eval

## 켜져야 할 요청
1. 보강 신청 기능 사용 설명서 만들어 줘. 계획서랑 캡처 폴더 줄게.
2. 이번에 나온 전화 알림 기능 매뉴얼을 원장님들께 드릴 PDF로 만들어 줘.
3. 학원 안내 PDF 하나 필요해. 행정팀이 출결 화면에서 새 버튼 쓰는 법을 따라 할 수 있게.
4. 강사님용 기능 매뉴얼 만들어 줘. 캡처는 Downloads 폴더에 있어.
5. 이 기능 처음 쓰는 원장님한테 보낼 사용 설명서 만들어 줘. 캡처에 실제 학부모 번호가 찍혀 있어.

## 켜지면 안 될 요청
다른 스킬이 맡는 말을 넣는다 (`docs/01-트리거 지도.md`의 "겹치는 말 정리").

| 요청 | 대신 맡는 스킬 |
|---|---|
| 원장님 인터뷰한 거 리포트로 정리해서 PDF로 줘 | `research-report` |
| 팀 회의용 HTML 페이지 하나 만들어 줘, 우리 팀 토큰으로 | `artifact-style` |
| 출결 관리 화면에서 지각이랑 결석 정책이 어떻게 달라? | `tikita-policy` |
| 이 staging 화면 피그마로 떠서 개선 시안 얹어 줘 | `screen-to-hifi` |
| 이 기획서 개발로 넘기기 전에 프로토타입이랑 맞는지 확인해 줘 | `handoff-check` |

## 기능 확인
입력은 `plugins/ux-team/skills/feature-guide/references/example/`의 가상 예시 세트다 (계획서 1개 · `원본/` 캡처 2장과 가공 spec · 원고).
시험 출력은 임시 폴더에만 둔다.

| 확인 | 화면 | 기대 결과 | 관련 ACC |
|---|---|---|---|
| `원본/` 캡처 2장을 `annotate.swift`와 `원본/*.json`으로 가공 | Code 탭 | 가공본이 `references/example/`의 가공본과 바이트 단위로 같다. `홍길동` · 전체 전화번호가 남지 않는다 (렌더 PNG를 눈으로 확인) | ACC-17 |
| 가공본과 원고로 `/usr/bin/python3`(3.9)에서 `build_guide.py` 실행 | Code 탭 | PDF 4쪽(표지 + 단계 2쪽 + 이럴 땐 이렇게), 이미지 2장, 로고 · 번호 배지 · side 배치가 보인다 | ACC-15 |
| 같은 입력으로 Homebrew Python(3.12 이상)에서 실행 | Code 탭 | 위와 같은 쪽 수와 내용 | ACC-15 |
| 캡처 없이 원고만으로 빌드 | Code 탭 | 실패하지 않고 `캡처 없음` 자리만 남기며, 빠진 파일 이름을 알린다 | ACC-15 |
| Chat에서 "보강 신청 사용 설명서 만들어 줘" | Chat | SKILL.md "Chat · Cowork에서 불렸을 때"의 안내를 출력하고 멈춘다. 원고를 쓰지 않는다 | ACC-16 |
| Cowork에서 같은 요청 | Cowork | 위와 같다 | ACC-16 |
| `python3 scripts/skills.py check feature-guide` | Code 탭 | 문제 0건. 다른 스킬 폴더 참조 · 리드 vault 경로 · 리드 PC 메모가 없다 | ACC-14 |
