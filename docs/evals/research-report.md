# research-report eval

## 켜져야 할 요청
1. 어제 A학원 원장님 인터뷰한 메모야. 인터뷰 정리해 줘
2. 구글 폼 설문 결과 CSV 올렸어. 응답 두 개뿐인데 설문 결과 리포트로 만들어 줘
3. C학원에서 새 출결 화면 현장 테스트한 질문 리스트야. 현장 테스트 결과 정리해서 팀에 공유하고 싶어
4. 원장님 두 분한테 같은 질문으로 인터뷰했어. 두 분 답 나란히 비교해서 리포트로 만들어 줘, PDF로
5. 현장 관찰 메모랑 녹음 요약 붙일게. 응답 정리해서 HTML 리포트로 뽑아 줘

## 켜지면 안 될 요청
다른 스킬이 맡는 말을 넣는다 (`docs/01-트리거 지도.md`의 "겹치는 말 정리").

| 요청 | 대신 맡는 스킬 |
|---|---|
| 출결 관리 새 기능 원장님용 사용 설명서 PDF 만들어 줘 | `feature-guide` |
| 이번 분기 로드맵을 팀 토큰 입혀서 HTML 페이지로 만들어 줘 | `artifact-style` |
| 미납 안내는 문자 먼저 보내기로 했어. 결정 기록 남겨 줘 | `decision-log` |
| 기획서랑 프로토타입이 맞는지 넘기기 전에 확인해 줘 | `handoff-check` |
| staging에 올라간 출결 화면이 의도대로 구현됐는지 봐 줘 | `intent-check` |
