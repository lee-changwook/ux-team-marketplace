# call-lead eval

ACC · DEC · QST 번호는 `docs/00-명세.md`, CRS 번호는 `shared/crossings.md`의 것이다.
장소(`team-places.md`)가 `<미정>`인 동안은 기능 확인을 초안 출력까지만 한다. ClickUp 댓글 · Slack 발송 확인은 리드가 시험용 태스크와 채널을 정해 준 뒤에 한다.

## 켜져야 할 요청
1. 창욱님 불러 줘. 결제 내역 프로토타입에서 환불 행을 어떻게 그려야 할지 모르겠어
2. 막혔어. 재원생 목록 응답에 분반 정보가 어디 있는지 모르겠어
3. 리드한테 물어봐 줘, world 브랜치에서 수업 그룹 선택이 안 돼
4. 데이터 구조가 불확실해서 리드한테 물어봐야 할 것 같아
5. 프로토타입 만들다 막혔어, 리드 좀 불러 줘

## 켜지면 안 될 요청
다른 스킬이 맡는 말을 넣는다 (`docs/01-트리거 지도.md`의 "겹치는 말 정리").

| 요청 | 대신 맡는 스킬 |
|---|---|
| 출결 상태에서 지각과 결석은 어떻게 달라? | `tikita-policy` (정책 질문은 먼저 위키에서 찾는다) |
| 프로젝트 배정됐어, 상위 태스크 만들어 줘 | `kickoff` |
| 넘기기 전에 확인해 줘 | `handoff-check` |
| staging 확인해 줘 | `intent-check` |
| 리드랑 정한 거 결정 기록 남겨 줘 | `decision-log` |

## 기능 확인
| 확인 | 화면 | 기대 결과 | 관련 ACC |
|---|---|---|---|
| 막힌 지점 · 데이터 구조 · 브랜치 · 재현 방법과 상위 태스크 링크를 주고 실행 | 모두 | 댓글 초안(여쭤볼 것이 맨 위, 다섯 절)을 보여 주고 "이 댓글을 올릴까요?"에서 멈춘다. 게시 · 발송 호출이 0건이다 | ACC-40 |
| 댓글 초안 안의 멘션 | 모두 | 댓글에 멘션이 없다 | ACC-42 |
| Slack 초안 (댓글 링크는 자리표시로) | 모두 | 새 스레드는 `[PRJ-NNN] 이름 · 중간 확인 <댓글 링크> @리드`, 답글은 `<댓글 링크> @리드`만 있다. 댓글 내용이 한 줄도 없다 | ACC-41 · ACC-42 |
| "유진님도 같이 불러 줘" | 모두 | Slack에서는 리드만 부르고, 다른 사람은 ClickUp 댓글에서 부르라고 안내한다 | ACC-42 |
| Slack 표가 `<미정>` | 모두 | 어느 채널에 보낼지 묻는다. 채널을 지어내지 않는다 | ACC-40 |
| 상위 태스크가 없음 | 모두 | `kickoff`로 먼저 등록하라고 안내하고 멈춘다. Slack에 바로 보내지 않는다 | — |
| Slack 커넥터만 없음 | 모두 | Customize › Connectors를 안내하고 멈춘다. 댓글만 올리고 끝내지 않는다 | — |
| 댓글 승인 → 게시 → Slack 승인 → 발송 (시험 태스크 · 채널 필요) | 모두 | 확인을 두 번 받는다. 같은 프로젝트로 두 번째 부르면 첫 스레드의 답글로 간다. 채널에도 보내기가 꺼져 있다 | ACC-40 |
