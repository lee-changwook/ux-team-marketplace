# kickoff eval

ACC · DEC · QST 번호는 `docs/00-명세.md`, CRS 번호는 `shared/crossings.md`의 것이다.
장소(`team-places.md`)가 `<미정>`인 동안은 기능 확인을 초안 출력까지만 한다. ClickUp에 만들거나 조회하는 확인은 리드가 시험용 리스트를 정해 준 뒤에 한다.

## 켜져야 할 요청
1. 오늘 전사 미팅에서 정산 관리 프로젝트 배정됐어
2. 상위 태스크 만들어 줘. 이름은 출결 알림 개편, 배정일은 10/14야
3. 킥오프 등록해 줘, PRJ-031 수업료 납입 증명서
4. 새 프로젝트 배정됐는데 팀 스페이스에 올려 줘
5. 프로젝트 배정됐어. 담당은 나고 배경은 학원 원장님 요청이야

## 켜지면 안 될 요청
다른 스킬이 맡는 말을 넣는다 (`docs/01-트리거 지도.md`의 "겹치는 말 정리").

| 요청 | 대신 맡는 스킬 |
|---|---|
| 정산 관리 상위 태스크 이름 바꿔 줘 | 없음. 기존 태스크 수정은 맡지 않는다 |
| 막혔어, 창욱님 불러 줘 | `call-lead` |
| 이거 결정됐어, 기록 남겨 줘 | `decision-log` |
| 넘기기 전에 확인해 줘 | `handoff-check` |
| 출결 관리 페이지에서 지각 정책이 뭐야 | `tikita-policy` |

## 기능 확인
| 확인 | 화면 | 기대 결과 | 관련 ACC |
|---|---|---|---|
| 이름 · 배정일 · 담당 · 배경을 주고 실행 | 모두 | 초안(위치 · 이름 · 담당 · 시작일 · 설명 · 서브태스크 "개발 전달")을 보여 주고 "이대로 만들까요?"에서 멈춘다. 만들기 호출이 0건이다 | ACC-34 |
| 초안에 "음…"처럼 애매하게 답함 | 모두 | 만들지 않고 다시 묻는다 | ACC-34 |
| `team-places.md` 상위 태스크 행이 `<미정>` | 모두 | Space · List를 묻는다. 비슷한 리스트를 골라 쓰지 않는다 | ACC-34 |
| 배경을 주지 않음 | 모두 | 초안의 배경이 `미결`이다. 배경을 지어내지 않는다 | — |
| PRJ 번호 없음 | 모두 | 한 번 묻고, 없다고 하면 이름에 `[PRJ-NNN]` 없이 이름만 쓴다 | — |
| 리스트에 `[PRJ-030] 정산 관리`가 있는데 "정산관리"로 실행 (시험 리스트 필요) | 모두 | 초안보다 먼저 같은 이름 태스크의 이름 · 상태 · 담당 · 링크를 보여 주고 새로 만들기 / 기존 쓰기 / 그만두기를 묻는다. 닫힌 태스크도 찾는다 | ACC-35 |
| 찾기가 실패함 (시험 리스트 필요) | 모두 | 만들지 않고 실패를 알린다 | ACC-35 |
| 승인 후 만들기 (시험 리스트 필요) | 모두 | 상위 태스크와 "개발 전달" 서브태스크의 링크를 준다 | ACC-36 |
| ClickUp 커넥터가 없음 | 모두 | Customize › Connectors를 안내하고 멈춘다 | — |
